# Бренд-наставник

Веб-приложение для ведения клиентов по созданию личного бренда или бренда компании с помощью нейросетей (ChatGPT, Claude).

Выросло из рабочей таблицы с промптами: те же шаги, но собранные в программу из 12 блоков, с заданиями для клиента, промптами в одну кнопку, полями для ответов и автоматической «библией бренда».

## Что умеет

- **Клиенты** — отдельная карточка и прогресс для каждого клиента (или для себя).
- **Программа из 12 блоков** — от распаковки личности до запуска и аналитики. Блоки можно отключать под конкретного клиента.
- **Каждый шаг**: цель, задание, вспомогательные вопросы, промпт (кнопка «Скопировать» + ссылки на ChatGPT и Claude), поля для ответов и таблицы, заметки наставника, статус.
- **«Задание клиенту»** — копирует готовый текст задания с промптом, чтобы отправить в мессенджер.
- **Библия бренда** — все ответы клиента одним документом: PDF (через печать), Markdown или копирование.
- **Методика** — как вести клиента: форматы работы, карта недель, структура встречи, контрольные точки, ошибки.
- **Резервная копия** — выгрузка и загрузка всех данных в файл `.json`.

## Где хранятся данные

Только в браузере, на устройстве, где вы работаете (localStorage). В репозиторий и на сервер ничего не уходит. Чтобы перенести данные на другое устройство или не потерять их — скачивайте резервную копию на главной странице.

## Как открыть

**Локально:** скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` в браузере.

**Как сайт (GitHub Pages):** Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save. Через минуту приложение будет доступно по адресу `https://ilonayanaitis.github.io/project/`.

## Как менять методику

- Шаги, промпты, задания и вопросы — `js/program.js`.
- Тексты раздела «Методика» — `js/guide.js`.
- Внешний вид — `css/styles.css`.

Важно: если менять `id` шага, ранее сохранённые ответы по нему перестанут отображаться.
